# Site coaching Lina Salmi El Idrissi

Site statique (une page) tiré de la plaquette « Prestations & Tarifs ».

- `index.html` : la page, générée par `outils/build.py`
- `style.css` : couleurs et polices (beige #cbb5a0, brun #8e735b, Anton + Montserrat)
- `img/` : photos

Mettre à jour un tarif : modifier le prix dans `outils/build.py`, puis lancer
`python3 outils/build.py .` depuis la racine du dépôt.
